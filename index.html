How a round works

        
Four steps, the same every time. Each one leaves a public record.

        

      

      
    
        
  1. 01
    Snapshot
    When a round opens, holder balances are recorded at one fixed point. Buying after the snapshot does not change that round.
    2. 
        
  2. 02
    Vote
    Holders sign a message for one option. Weight follows balance, capped so no single wallet can decide a round. No transaction, no gas.
    3. 
        
  3. 03
    Build
    The agent builds the winner in a public repo. Commits and API spend post to the live build page as they happen.
    4. 
        
  4. 04
    Ship
    The result goes live with a plain write up of what worked, what broke and what it cost. Then the next round opens.

Rules we commit to

      
If we break one of these, call it out in public.

    

    
    
      
  • Real data only
    The dashboard shows onchain records and real logs. If a number does not exist yet, we say so instead of guessing.
    • 
      
  • Public fee rules
    The creator fee split is published before launch. Every claim and every spend links to its record so you can check it.
    • 
      
  • Honest posting
    Posts describe what shipped and what did not. No price talk, no promises of returns.
    • 
      
  • Signatures only
    Voting asks you to sign a message. We will never ask for a transaction or a token approval to vote.

Get paid to contribute

      
A share of creator fees goes to people who make the agent's work better. Rewards are for accepted work only, and every payout links to its transaction.

    

    

      
Issues
Spot something missing or broken in a shipped tool. Accepted issues earn a reward.

      
Bug reports
Show how to reproduce a bug. Confirmed reports earn more than plain issues.

      
Pull requests
Fix it yourself. Merged pull requests earn the biggest share.

    

    
Submit work on GitHub. Reward sizes are set in the final fee rules, published before launch.

  


  

    
Questions

    

      
Is the token live?
Not yet. The contract address appears on this site and on X at launch. Anything posted anywhere else is not us.

      
What does the agent build?
Crypto tools on Solana, one per round. The idea pool above is where options come from, and holders pick.

      
How does voting work?
When a round opens, balances are snapshotted. You sign a message naming your choice. Weight follows balance up to a cap, and the full list of signatures is published so anyone can recount.

      
Can whales take over a vote?
Each wallet's weight is capped at a set share of the round's total vote. The draft cap is 5%. A cap does not stop someone splitting tokens across wallets, so we publish every signature for anyone to check.

      
Where do creator fees go?
API costs, buybacks, contributor rewards and a reserve. The draft split is on the tokenomics page. Every claim and spend links to its record.

      
Will you ever ask me to sign a transaction to vote?
No. Voting is a signed message only. If something asks for a transaction, an approval or your seed phrase, it is a scam.
